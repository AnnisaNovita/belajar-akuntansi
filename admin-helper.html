💡 Cara Memasukkan Kode Ini Ke Proyek:

  1. Klik tombol **"Hasilkan"** untuk memproses isian form di atas.
  2. Klik tombol **"Salin Kode 📋"** untuk menyalin baris data JSON tersebut.
  3. Buka file materi.json (atau kuis.json untuk kuis) menggunakan Visual Studio Code di komputer Kakak.
  4. Tempel kode tersebut di baris paling bawah di dalam daftar yang sesuai. Jangan lupa tambahkan tanda koma (,) sebagai pembatas antardata!
  5. Simpan, lalu lakukan **Push** atau upload perubahannya ke GitHub Kakak. Netlify akan otomatis memperbaruinya dalam hitungan detik!
